I used the LLM to help understand the probabilistic language model, write the Python implementation, and explain the concepts behind the Bayesian network and conditional probabilities. I did not assume that the generated code was automatically correct. I checked the transition counts, probability distributions, and the normalization property that all conditional probabilities for a given context must sum to 1.

One example of correcting the LLM-generated code was the sentence generation function. The initial implementation used greedy generation without a maximum number of steps. When I tested it, the greedy model became stuck in a cycle such as "the -> cat -> sat -> on -> the" and never reached the <END> token. I corrected this by adding a maximum number of generation steps to prevent an infinite loop. This showed the importance of running and testing LLM-generated code rather than relying only on its explanation.
